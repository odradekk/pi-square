Add live streaming to the subagent transcript viewer: while a child runs, the overlay shows its in-flight assistant message (ordered text/thinking parts through the shared bounded projection) and live tool rows with immediate terminal states as a bounded tail below the persisted history. Delivery is decoupled from the child run: publication enqueues into a bounded ordered feed that delivers exactly one event per scheduler tick, never inside the child's event dispatch, with time-budgeted subscriber callbacks (an overrunning listener is evicted) and overflow that drops the oldest past explicit omission markers carrying the dropped entries' fingerprints. Ordinary repaints coalesce through one session-owned timer while structural events render immediately. A completed message is confirmed only by the persisted occurrence carrying the same bounded content projection and native message timestamp, each occurrence consumable at most once for the overlay's lifetime, so delayed delivery, terminal reconciles, pre-existing identical history, and repeated identical completions can neither duplicate nor strand content; live tool rows reconcile by a non-reversible key of the native call identity (the raw id never enters a projected item). Overflow of the tail or the feed stays visible as a bounded omission state that clears only when persisted history actually recovers the dropped entries. Observer failures never reach the child.

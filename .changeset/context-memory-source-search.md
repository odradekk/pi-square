Minor: bounded Context Memory source search with precise page references (#339)

- Adds the parent-only `search_memory_source` tool, registered through the existing Context Memory registrar and active exactly while `read_memory_source` is (enabled feature, supported host, strictly valid non-empty current Memory). It accepts 1–8 non-empty literal terms (each at most 120 characters; whitespace-only refused) with case-insensitive OR semantics — no regular expressions, fuzzy matching, external services, or extra model calls — plus an optional 1-based `block` selector.
- Search runs over exactly the transcript `read_memory_source` serves: the same renderer, the same fixed 16 KiB UTF-8-safe pages, never Memory summaries, prior read/search copies, protocol artifacts, or sibling branches. Matching happens over each block's complete rendered source through a per-code-point case fold that preserves exact original-text offsets, then maps hit byte ranges onto the pages, so a phrase crossing a page boundary stays discoverable and its row names both pages; no match is manufactured across blocks, omitted artifacts, or excerpt gaps.
- Results are bounded and truthful: grouped block/page rows in stable source order with matched-term attribution and at most two verbatim excerpts per row, at most 12 rows per response under an 8 KiB cap, with omitted rows, excerpt overflow, and any scan stopped at the 4096-match bound reported explicitly. A complete zero-hit search states that the literal terms did not occur in the searched sources — never that a fact is absent.
- Returned locations bind to an opaque source-view token (a one-way digest of the current Memory derivation). `read_memory_source` gains the optional `view` argument: a read pinned to a stale token fails with `VIEW_STALE` before any page content is served after an append, rebuild, branch change, native compaction, or session change, while ordinary direct block/page reads stay unchanged.
- Search call/result pairs receive the same retrieval-protocol treatment as reads: visible in their own run, excluded from every future Memory source stream, and preserved as whole native call/result pairs through later compression and projection. Searching is observational — it mutates no Memory state, invites no compression, satisfies no maintenance source-serving authorization, and adds no index, cursor, cache, sidecar, or ledger.

Keep recorded Context Memory truthful across interruptions and native Pi session branches (odradekk/pi-square#322, ADR-0017)

- Fixes a lifecycle defect in the append source selection: an unanswered Context Memory protocol call — a compression or source-reading tool call left without its result by an aborted batch or by a native branch cut at the recorded state entry — permanently blocked every later append on that branch, because the batch-pairing orphan check treated it like unanswered conversation evidence. Protocol calls are bookkeeping the request-side pair rules already drop from provider requests, so they no longer participate in the orphan check; an unanswered ordinary tool call inside a covered range still refuses the compression, exactly as before.
- Pins the full interruption and branch lifecycle matrix with deterministic tests against real Pi `AgentSession`s over persisted session files, using native tree operations (`navigateTree`, `createBranchedSession`, cross-directory copies) and the provider-request exit as the observation seam: a cancellation before the write records nothing and the same session can still record; a cancellation after recording keeps the real record with its truthful acknowledgement; restart replays no unrecorded candidate or advisory, fabricates no request before the next ordinary prompt, and re-derives the byte-identical carrier, replacement set, and source pages; fork, clone, import, and in-file sibling branches stay isolated in both directions with the append prefix byte-stable across siblings; a later native compaction becomes the new baseline without stacking or resurrection and compressing over it refuses with a bounded `MEMORY_CHANGED`; a write failure through the `appendEntry` seam leaves previously recorded Memory intact; disabling the feature makes raw history model-visible again without touching the session file; and ephemeral in-memory sessions run the same behavior with no files. Aborts are coordinated from session events (a tool-result `message_end`, a counted `turn_start`), never timers.

Commit the first main-agent-authored Memory block through the full handshake

Adds the first write path for experimental Context Memory on top of the default-off shell and reading surface (odradekk/pi-square#218, parent spec #215). The feature stays default-off; appending further blocks and rebuilding the suffix arrive with later slices.

- Due detection uses the configured percent/token threshold capped ten percent of the context window below Pi's native compaction boundary (Pi's reserve read through its public SettingsManager), disabling structured takeover when the clamped point is non-positive or the Memory budget is not strictly smaller. The due flag is recomputed at session start, model selection, and agent settle from numeric Pi usage or one deterministic chars/4 estimate over Pi's own projection; no counter persists and nothing wakes the agent autonomously.
- Only a real-user (interactive or RPC) input opens a due handshake and activates the parent-only `submit_memory` tool before request construction; steering keeps the open run, extension-origin continuations never open one, and each new real-user run clears the transient state first.
- The first provider request of a due run carries one ephemeral non-display advisory after the current user message — complete the task first, then one final sole `submit_memory` call, no credentials copied — appended through Pi's `context` transform, never persisted and never repeated. `submit_memory` call parts and paired results leave every provider-bound request while ordinary assistant text survives.
- `submit_memory` validates the strict one-field schema, the sole-tool-call batch, the idle transaction slot, and the 16 KiB body bounds, then stores a run-scoped candidate bound to the current leaf, run, tool-call id, retained-tail boundary, source end, and model budget. It returns the fixed pending acknowledgement with `{ accepted: true }` and terminates the tool batch; safe short-code refusals (`SUBMIT_NOT_DUE`, `SUBMIT_NOT_SOLE_TOOL`, `COMPACTION_BUSY`, `BOUND_EXCEEDED`) never echo Memory Markdown.
- At settle, a pending candidate is committed through Pi's public compaction seam exactly once without another model call: `session_before_compact` re-derives and exactly matches the branch snapshot, then returns the composed wrapper/summary/directory with the current real-user request as `firstKeptEntryId` and Pi's own preparation token accounting; `cancel` is never returned, so any mismatch falls back to Pi native compaction. Success is confirmed only from the actual saved entry's extension origin, summary, kept boundary, and directory — a competing entry clears the slot with one bounded `COMPACTION_CONFLICT` diagnostic.
- `/context` adds the `due`, `pending`, and `committing` handshake states; abort, tree navigation, model change, and reload discard transient state; the tools stay absent from every child catalog.

Insert one or more literal lines into a text file immediately before or after one observed line, targeted by its 3-char HASH anchor from read output. The anchor line keeps its content; only the new lines are added. Prefer insert over replace when you are only adding adjacent lines — use replace when you need to modify or delete existing lines. anchor must be a BARE 3-character hash: copy only the hash from the leftmost column of a read row (row `aB3│function hello() {` means `"anchor": "aB3"`). direction is "before" or "after". lines is an ordered array of one or more strings; each item is exactly one logical line with no \n or \r inside — an empty string item "" inserts one real blank line — and items are inserted literally (no prefixes are stripped, duplicates are kept). The file's line-ending convention (LF, CRLF, or CR), BOM, and terminal-newline state are preserved; a blank line inserted after an unterminated last row adds the terminator it needs. An empty file reads as one synthetic anchor row (HASH│ with empty content): insert initializes the file with the given lines, and before and after are the same initialization. Reusing the same anchor inserts directly adjacent to that line each time. Requires a prior read (or a post-edit diff) of the same file version: anchors from an older version are refused with the current anchored context for an immediate retry. The file must already exist; insert never creates files.

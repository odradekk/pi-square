Read a text file; each line returned as HASH│content with a 3-char alphanumeric hash. No line numbers — use the HASH as the anchor in insert and replace calls. Images → visual attachments; Binary/directory → rejected; UTF-16/UTF-32 (BOM) → rejected; empty → HASH│ synthetic anchor (insert with it adds the first lines; before and after are the same initialization); pageable with offset/limit; BOM stripped; non-UTF-8 shown as U+FFFD.

Undo the last replace on a file, reverting it to its previous state. Use when a replace produced incorrect results (e.g., wrong content, duplicated lines, broken syntax). The parent session can revert the most recent edit to a file regardless of which agent made it, so a supervisor can roll back a subagent's mistake exactly, including byte order mark and line endings; a subagent can revert only an edit it made itself and is refused otherwise.
